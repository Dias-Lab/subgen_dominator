# Subgenome Dominance Predictor

This repository contains the preprocessing and machine learning pipeline for analyzing maize genomic duplication data. The project integrates diverse genomic features—including methylation, chromatin accessibility (ACRs), transposable elements (TEs), and histone modifications—to model subgenome evolution and duplication patterns.
